# Agent-Router — Backend Data (D1/DAO Layer)

Scope: `packages/backend-data/**`. Parent index: `../../AGENTS.md`.

- All D1 access via DAOs over `D1Queryable`: `BaseDAO` (`withRetry` + static `findById`/`deleteOlderThan` + instance `findRowById`/`deleteRowsOlderThan`/`encodeCursor`/`decodeCursor`), `UserDAO` (`upsertUser`/`getByEmail`/`getByUsernameCi`/`ensureUsername`/`setUsername`), `ProviderDAO` (per-user CRUD, unique `(user_email, name)`), `ProviderKeyDAO` (priority-ordered active list, `recordSuccess/recordFailure`, `markExhausted/clearCooldown`, `resetUsage/resetDueKeys`, `disableFailing`, cascade delete by provider, Codex OAuth `createOAuthKey/updateOAuthConnected/updateOAuthRefreshed(+Conditional)/setOAuthStatus/clearOAuth/listOAuthRefreshCandidates`), `CodexOAuthSessionDAO` (PKCE session create/`getActive`/`consume`/`deleteExpiredOrConsumed`), `GatewayKeyDAO` (hash lookup with expiry, per-user list, touch, revoke, prune), `UsageLedgerDAO` (insert, cursor-paginated `listByUser`, `summarizeByUser/summarizeByProvider`, prune).
- Utils: `D1Types` (`D1Queryable`), `D1Utils` (`executeD1WithRetry`), `D1ErrorClassifier` (retryable detection), `CursorUtil` (opaque pagination cursors). Hashing lives in `@agent-router/shared/utils` (`CryptoUtil.sha256Hex`); symmetric encryption lives in services (`KeyCrypto`), not DAOs.
- Migrations: `migrations/0001_agent_router.sql` (`users`, `gateway_keys`, `providers`, `provider_keys`, `usage_ledger`); legacy schema archived in `migrations/_archive/`; `migrations/0002_codex_oauth.sql` (OAuth columns on `provider_keys`, `codex_oauth_sessions` via `CodexOAuthSessionDAO`).
- Layer 2 (L0-only): import only `@agent-router/shared` + `@agent-router/backend-errors`; never `backend-runtime`, `backend-services`, or `apps/*` (enforced by `no-restricted-imports`).
