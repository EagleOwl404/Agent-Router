# Agent-Router — Backend Services

Scope: `packages/backend-services/**`. Parent index: `../../AGENTS.md`. Layer 3 (may use layers 0–2 only, never apps).

- Domain map:
  - `src/auth/AccessAuthService.ts` — `/user/*` identity: `DEMO_MODE` → `DEV_AUTH_EMAIL` → JWT (`cf-access-jwt-assertion` vs `TEAM_DOMAIN`/`POLICY_AUD`) → `ctx.access.getIdentity()` fallback. Never trust `Cf-Access-Authenticated-User-Email`.
  - `src/user/UserService.ts` — `upsertUser` (lowercased email, idempotent; bootstraps globally-unique username from email prefix) + `getProfileByEmail/getByUsername/renameUsername`.
  - `src/gateway/GatewayKeyService.ts` — client bearer keys: `ar_`+uuid mint, sha256 (`agent-router-gw:`) hash, `MAX_GATEWAY_KEYS_PER_USER`/`MAX_GATEWAY_KEY_EXPIRY_DAYS`; `authenticate` → `{userEmail, keyId}` + `last_used` touch; `revokeKey` (404 when unknown), `pruneExpired`.
  - `src/provider/ProviderService.ts` — provider CRUD per user (`OPENAI|ANTHROPIC|GEMINI|OPENAI_COMPAT|OPENAI_CODEX`, unique name, SSRF-guarded `baseUrl`; first-party kinds pin default endpoints, `OPENAI_COMPAT` allows custom https).
  - `src/provider/ProviderKeyService.ts` — key pools: AES-GCM encrypt on write (`KeyCrypto` purpose `provider-keys`, key from `PROVIDER_KEYS_ENCRYPTION_SECRET`), masked reads (hint only), `priority` ordering, `tokenLimit`/`requestLimit` caps, `resetInDays` rollover, rotate/reset/delete, `decryptSecret` for the proxy path only. Static secrets are rejected for `OPENAI_CODEX` providers and OAuth keys.
  - `src/codex/` — ChatGPT OAuth for `OPENAI_CODEX` (Otter `oauth2/` pattern): `CodexOAuthClient` (public client `app_EMoamEEZ73f0CkXaXp7hrann`, device-code request/poll, code exchange with the device redirect URI, refresh with rotation-retain, revoke, account-id JWT parse incl. the namespaced claim), `CodexOAuthService` (pending-key create, device-code start/poll over D1 `codex_device_sessions`, refresh-token import from Codex-app/OpenCode pastes, disconnect; `KeyCrypto` purpose `codex-oauth` via `CODEX_OAUTH_ENCRYPTION_SECRET`), `CodexTokenService` (cached access, single-flight + conditional-write refresh for single-use rotation, proactive `refreshExpiring`; same Codex OAuth key). Browser PKCE redirect was retired: OpenAI allow-lists the public client for localhost callbacks only.
  - `src/router/UpstreamClient.ts` — per-kind call builders (OpenAI Bearer, Anthropic `x-api-key`+version, Gemini `?key=`, Codex against `chatgpt.com/backend-api/codex` with Bearer + `ChatGPT-Account-Id` + Responses-beta/originator headers and body normalization for `input`/`store`/`stream`), `parseUsage` (OpenAI/Gemini `prompt/completion_tokens`, Anthropic/Codex `input/output_tokens`, estimated fallback), `extractCodexCompletedResponse` (SSE→JSON for non-streaming Codex clients), `isRetryableStatus` (429/502/503/504).
  - `src/router/RouterService.ts` — `proxy()`: cap-aware pick (`status=active`, cooldown elapsed, under caps; marks newly-capped `exhausted`; skips unconnected OAuth keys), per-key upstream fetch with `PROXY_TIMEOUT_MS`, success → usage record + ledger; OAuth 401 → one force-refresh retry; retryable failure → exponential `cooldown_until` (`KEY_COOLDOWN_BASE_MS`), auto-`disabled` past `KEY_MAX_CONSECUTIVE_FAILURES`; all-exhausted → `ExceededLimitError` (429), all-OAuth-blocked → reconnect `BadRequestError`. Non-retryable 4xx surfaces upstream with no failover.
  - `src/usage/UsageService.ts` — `getSummary(days≤90)` + cursor-paginated `listLedger` + `pruneOlderThan`.
- `src/composition/` — `Tokens` registry + `createRequestScope(env)`: per-request `Container`, table-driven lazy+memoized DAO factories (no Secrets Store round-trip until used), single `AppConfiguration`. Handlers resolve `scope.get(Tokens.X)`.
- Constructor injection: every service takes `(env, deps?)` with `() => Promise<DAO>` factories — tests override with stubs, no module mocks needed.
- Errors via `@agent-router/backend-errors` (`Bad/Unauthorized/Forbidden/NotFound/ExceededLimitError`); time/ids via `@agent-router/shared/utils` (`TimestampUtil`, `UUIDUtil`, `CryptoUtil`).
